# Contributing to Code Roaster (Desi Edition) 🌶️

Thank you for your interest in contributing to **Code Roaster**! This project was built during the **GDG Nashik Pre-DevFest 2026 Workshop**.

## 🚀 How to Contribute

1. **Fork the Repository** and clone it to your local machine.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/my-amazing-feature
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Set Up Local Secrets**:
   - Copy `.env.example` to `.env.local`
   - Add your Gemini API key from [Google AI Studio](https://aistudio.google.com/apikey).
5. **Run the Dev Server**:
   ```bash
   npm run dev
   ```
6. **Verify Your Changes**:
   ```bash
   npm run check:api
   npm run build
   ```
7. **Commit & Push**:
   ```bash
   git commit -m "feat: describe your change"
   git push origin feature/my-amazing-feature
   ```
8. **Submit a Pull Request** to the `main` branch.
